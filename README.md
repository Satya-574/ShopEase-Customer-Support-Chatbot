#ShopEase Customer Support Chatbot

AI-powered customer support chatbot for an online shopping platform.

Project Overview

ShopEase is an AI-powered customer support chatbot designed to help online shopping customers with their common queries quickly and efficiently.

Features

- Order Tracking Assistance
- Order Cancellation Support
- Returns and Refunds Information
- Payment Issue Assistance
- Delivery Information
- Damaged or Incorrect Product Support
- Account and Login Assistance
- Hindi and English Language Support

Technologies Used

- Chatbase
- AI / Large Language Model
- Knowledge Base (Data Sources)
